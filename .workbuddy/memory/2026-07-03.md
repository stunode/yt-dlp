## 讨论主题
1. Python 项目调试方法（vs Java 调试模型）
2. PyCharm 调试配置（`script` 模式 vs `module` 模式）—— 用户的 PyCharm 报 `No such file or directory: '-m yt_dlp'`，因为把脚本参数写进了 Script path
3. 给 yt-downloader-javavue (Spring Boot + yt-dlp) 增加 --cookies 支持
   - 项目已实现单站点 cookies 加载（`DownloadService.java` 第 153-171 行 `resolveCookiesPath`）
   - 现状：`yt-dlp.cookies-file` 只支持单一文件，不支持多站点按 host 自动选
   - 建议改造方向：按 host + 命名约定 `<host>_cookies.txt` 自动选文件
   - cookies 文件位置：`backend/src/main/resources/cookies/`
4. **macOS + PyCharm 调试 yt-dlp 的两个坑及解法**：
   - 坑 1：必须用 `module` 模式（Script 文本框填 `yt_dlp`），不能用 `script` 模式
   - 坑 2：macOS Python venv 缺 CA 证书，报 `SSL: CERTIFICATE_VERIFY_FAILED`
   - 解法：`pip install certifi` + 环境变量 `SSL_CERT_FILE=<cacert.pem 路径>`
5. 已生成项目文档 `docs/PYCHARM_DEBUG_GUIDE.md`，收录整套踩坑过程
